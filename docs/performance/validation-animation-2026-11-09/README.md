# 动画修复执行记录

基线：`perf/home-gallery-sorting`，`bb8a12307c811553964c2fdeab090cdda9254c95`。仅在本地工作，不连接或推送远端。

## 实现

- 共享导航关闭并行窗口动画及背景淡化；保留普通页面和底部根导航原有行为。
- PhotoFragment/VideoFragment 使用透明、按实际内容范围布局的 MediaSharedSurface，黑色留边留在父画布。
- 图片矩阵和边界共同动画；转场内延后深度缩放渲染器交接。
- 视频封面加载完成即可通知进入；首帧在共享期间不会撤去封面；播放后的返回捕获显示尺寸内的有效帧。
- 视频尺寸按实际容器计算，避免先用 1:1 临时尺寸或物理全屏尺寸。
- 普通目录与照片档案共用内部共享启动；用真实加载成功 token 区分占位和媒体。
- 返回结果携带当前页身份；源网格通过系统返回对应的 ExitSharedElementCallback 重映射，等待目标加载及预绘制，必要时定位离屏项目。
- 系统的 finishAfterTransition 与 finish 统一准备返回，防止先执行旧返回再更新映射。
- 返回结束后不提前恢复全屏渲染层；销毁时释放代理、恢复 alpha 并取消回调。
- 相册等待首屏可见缩略图稳定；封面不在首屏时降级，不改变用户排序位置。
- 移除将根页面标记误用于禁用后续相册封面转场的判断。
- 目录已加载缩略图不重复清空或淡入；保留复用清理和失败重试。
- 横滑标题在 IDLE 时更新，权限状态仍即时刷新；工具栏、播放按钮和进度条纳入共享转场的显隐时序；取消下滑不再关闭页面，下滑关闭不叠加额外 slide_down。
