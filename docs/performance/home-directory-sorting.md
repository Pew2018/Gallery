# 主页目录排序后台化

## 目标与范围

避免主页目录排序准备和计算阻塞 UI 线程，同时保持已有目录顺序规则、搜索结果、收藏/置顶/回收站优先级，以及过期任务不可覆盖较新状态的行为。本轮限于 `MainActivity` 主页目录网格；不改变媒体扫描策略、PhotoProfile/Viewer、数据库 schema 或持久缓存。

## 实现记录

- 分支：`perf/home-gallery-sorting`
- 基线：`main` / `b308a2132`
- 排序实现：提交 `5532aae2e818e837ce82928fadc4db4ddb45be24`
- 工作流配置：提交 `5165a9dbe304ae547b67020a78ed6f784e3cecd3`
- `HomeDirectorySorter` 将目录列表复制后执行键准备、稳定排序、搜索匹配和主页优先级整理；提供中断检查以响应取消。
- 排序选项包含自定义顺序、收藏、回收站位置、随机顺序、数字自然排序及 Locale。
- `MainActivity` 将工作调度到后台，并在结果返回时校验当前请求/配置，避免旧结果覆盖新状态；现有目录适配器继续负责显示提交。
- 新增 `HomeDirectorySorterTest.kt`；测试文件存在，但本记录尚无执行结果。
- ARM64 FOSS Release workflow 增加 `perf/home-gallery-sorting` push 触发；仅配置已提交，尚未核实该分支的 Actions 运行结果。
