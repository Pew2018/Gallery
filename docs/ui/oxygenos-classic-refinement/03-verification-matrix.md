# 03 · 验证矩阵与视觉验收合同

> 此文档描述计划的测试，并非已经完成的测试记录。旧 `docs/testing/classic-motion-device-checks.md` 可继续用于底栏/Ripple/加载时序的设备检查。

## 1. 验证层级

| 层级 | 用途 | 不能代替 |
|---|---|---|
| 静态审计 | XML、资源、MenuItem ID、依赖及代码路径 | 实际设备绘制 |
| Robolectric/确定性测试 | View hierarchy、bound、layout、state、RTL、callback 取消、动画关闭 | GPU Ripple、SurfaceFlinger 动画 |
| GitHub Actions FOSS Release | 单元测试与编译、APK 产物/ABI | 真机视觉/系统 IME/手势 |
| 真实设备录屏与布局测量 | 菜单位置、阴影、触边、动画连续性 | 数据正确性与权限覆盖的全部自动化测试 |
| 用户确认 | 与 OxygenOS 7.1.1 参考视觉是否符合主观目标 | 程序稳定性验证 |

## 2. 最小设备与配置矩阵

**新增主题维度**：至少 3 个实际 Gallery 预设、用户自定义高亮/极浅/极暗/低对比色（含可能有 alpha 的颜色），分别在浅色/深色/Oxygen 主题关闭的 Commons 回退模式下检验；任何选中、按压、焦点、进度、Edge Glow 颜色都不允许仍固定旧蓝。Toolbar 白前景、错误红、沉浸黑底按既有语义独立测试。参见 [10](10-accent-semantic-and-runtime-invariants.md)。

- **基准设备**：Pixel 8 Pro 或同级真机，记录实际 Android 版本、逻辑密度、刷新率、屏宽 dp、导航模式、字体缩放、系统动画缩放和 APK commit。
- **屏幕宽度**：至少 320、360、412、600dp（可用 emulator + 真机组合；不是要求目标真机改变物理尺寸）。
- **方向/语言**：竖屏、横屏、系统中文、英文长字符串、RTL（例如阿拉伯语资源/布局方向）。
- **主题**：浅色、深色、自定义 accent、自定义工具栏底色及动态文字对比度。
- **字体**：默认、1.3x、1.5x；条件允许再测更大字体和 Display size。
- **动画**：系统动画缩放 0 / 1x；普通手势按压、长按、拖出取消、双击和快速跨页面切换。
- **数据**：空目录/单项目/大量项目、收藏/普通/含 .nomedia 文件夹、照片配置/受保护来源、刷新/扫描中、慢存储、权限拒绝。

录屏需开启显示触摸位置，尽可能以原生刷新率逐帧观察。记录相机拍摄素材/个人照片须打码、仅保留必要 UI。CI 通过不等于真机通过。

## 3. 按模块逐项回归

| 模块 | 测试动作 | 期望与可量化记录 |
|---|---|---|
| Popup 位置 | 主页、收藏、文件夹、Viewer、选取器；LTR/RTL；3、10、20+ 项 | 记录 anchor 与 Popup rect、左右边缘相差 dp、可见安全区；不裁剪末项 |
| Popup 宽度 | 短/长中文、英文、收藏双态文字、其他带 CheckBox/子菜单 | 记录文本测量宽、实际宽、左右 padding；收藏两行不预留旧勾选框宽度，其他控件不能被覆盖 |
| 收藏双态文字菜单 | 两项独立启停的四种组合、退出/重进、切主题、认证取消 | 两项 `checkable=false` 且无勾选框；false 显示“显示已排除项目/显示隐藏项目”，true 显示“不显示已排除项目/不显示隐藏项目”；点击按原逻辑翻转配置、刷新列表，认证取消沿用现有语义 |
| Popup Ripple | 正常点按、长按、按住滑出、重复打开、快速取消 | 一次点击一次 action；状态与 Ripple 不粘住、不溢出 |
| Settings Hub | 八分类行与分割线、分类跳转和返回 | icon/titles/summary 基线一致，主副标题自然换行，当前分类正确 |
| Settings 内页 | 分组标题与关联开关、隐藏条件项、顶部/底部滚动 | 没有孤立分组/重复 Divider；最后一项可被看到/点击 |
| Settings 动画 | 前进、立即返回、快速多次跳转、中途销毁、0x | 最终 alpha=1, translationX=0；不会恢复过期页面 |
| 底栏几何 | 三个根页面、顺序重排、旋转 | 56dp 基准、标签 12sp、图标 24dp；重排后仍可触达 |
| 底栏交互 | 单击/长按/快速跨 2–3 项/触摸取消 | ripple 完整、只有一次导航、最终选中正确 |
| 底栏切页 | 冷启动/缓存热/慢扫描/空页/受保护来源 | 统计错误颜色帧、白黑闪帧、错误数据闪帧；目标均为 0 |
| 搜索 | 展开、输入、删除字符、取消、键盘收回、搜索中切 tab | 查询内容立即响应，显示列表与输入一致，不丢输入焦点 |
| 输入字段 | 联系人风格下划线、对话框 EditText、旋转/IME | 焦点正确，光标可见，无键盘遮挡/输入文字抖动 |
| 顶底 EdgeEffect | 到边界、缓慢/快速拉动、松开、滚动中刷新 | 反馈短暂、颜色跟随主题；不影响滚动锚点 |
| Picker/Dialog | 文件、媒体、密码、日期、EXIF、属性、多选 | 原高宽策略/回调/授权正确；长内容滚动可达 |
| Predictive back | 边缘手势半途取消/完成、按钮返回、IME 打开、已授权/未授权 | 无副作用、手势取消原状恢复、状态清晰；参见 04 |

## 4. 新增/扩展测试建议

**新增 Material Motion 稳定性层**：根据 [11](11-legacy-material-motion-selection.md) 分清 AndroidX View、平台 Activity/Window、AppCompat Popup/AlertDialog；先检查实际依赖版本及 FOSS Release 可编译性。每一种新 Transition 测快速重入/取消、动画比例 0、主题中途更换/不闪旧色、经典控件最终几何不变；没有稳定双 View 时不强制使用 SharedAxis。

1. **菜单**：扩展 `ClassicOverflowPositionTest`：实际 PopupWindow rect、RTL、条目数 3/20、对齐及超界。新增 `favorite_always_show_excluded/hidden` 的非 checkable 菜单行、无勾选框/旧右边距、动态标题与四种配置组合测试；**不再把原 CheckBox 缺失根因排查作为交付条件**。
2. **布局**：增加设置分类行和 section 的 Native Raster + 不同 fontScale/宽度测试；保护保留 icon/titles/summary 的可读边界。
3. **底栏**：扩展 `GalleryBottomBarRippleTest`，严格保证同一 RippleDrawable 实例未被 recolor 重建、快速切换只有一次导航；切换动画取消时颜色最终正确。
4. **输入**：扩展 `ClassicToolbarLayoutTest` / 搜索交互测试，校验焦点、IME 消退、输入文字到列表更新的延迟不会由动画追加。
5. **页面动画**：扩展 `SettingsPageMotionTest` 的“反向切换/销毁/0x”和页面滚动位置恢复。
6. **预测性返回**：加入 0–1 手势进度、取消中途、完成一次、屏内/跨 Activity 及不同系统版本的测试（仅在 Phase 4 实施）。
7. **隐私与数据**：继续运行既有媒体管线、收藏、Viewer 顺序和删除恢复回归；UI 精修不改变这些合同。

## 5. 定量验收门槛

| 新增约束 | 验收条件 |
|---|---|
| 用户强调色 | 用户自定义和预设色下所有主题强调控件由 `OxygenThemeEngine.snapshot()` 派生、无硬编码参考蓝；深浅/不同 surface 对比正确 |
| 运动与形态分离 | 新 Material Motion 不改变 56dp Toolbar、经典 Popup/按钮/底栏、Dialog 宽高圆角、Switch 几何 |
| 依赖与窗口所有权 | AndroidX Material Transition 只用于确实有 View/Fragment 容器的场景；Popup/Dialog 窗口独立验收；真实 Gradle 编译通过 |
| 并发/动画竞争 | 主题切换/窗口关闭/返回取消/旋转/0x 后无残留 alpha、旧强调色或旧数据，权限/业务操作一次且及时 |

以下保留原有各项验收门槛：

| 指标 | 目标 |
|---|---|
| 菜单越界 | 0 个必要操作项不可达；长菜单可滚到最后一项 |
| 菜单锚点 | 在 Phase 0 实测确认的基准宽度上，与选定参考锚点误差控制在约 8dp 以内（初拟，可因平台/RTL 调整） |
| 收藏两条菜单 | 两项组合的 4 种配置状态均显示正确的下一步操作文字；无 CheckBox/Radio；点击、重开、旋转、持久化、认证取消各路径均通过 |
| 错误全屏闪帧 | 冷/热/慢扫描切 tab 的错误底色和旧媒体内容闪帧 0 |
| 导航重复执行 | 正常单次点按、快速连点均无重复启动 |
| 设置页面动画最终态 | 每种取消/完成/销毁用例 alpha=1、translationX=0，不复活过期变更 |
| 搜索数据一致性 | 输入状态与最终显示数据一致；不得因动画增加数据更新等待 |
| 受保护媒体 | 未授权/权限撤回时 0 次受保护缩略图提前曝光 |
| 可访问性 | 触摸区原则上 48dp 及以上；高字体/RTL/TalkBack 可达、含语义描述 |
| 系统动画关闭 | 所有新增动画应跳过/归位，不留半透明、偏移或卡住的控件 |

关于 0 闪帧：这是目标；若特定设备/测试配置确实观察到非零，必须报告根因、帧数和录像，不可声明完成。
