# 阶段 5C 修订：选择态动效对齐 + 顶栏不因选择变色

日期：2026-11-27（香港时间）。工作分支 `cursor/selection-theme-chrome-motion-c1c3`，起点为 `origin/perf/home-gallery-sorting` tip `f184acf7b0cd1030fdaef5e57539b6d131ed3ed9`（工作区干净）。未在 `main` 上改。阶段 3.5 顶栏等高、主页进度条删除保持不变。未重做 Viewer 返回、下拖、预测性返回、文件夹页动画、设置入场；未开 4A/4B/5A/5B/6A/6B；未重开阶段 7 全局时长体系。

## 改了什么

### 1. 顶栏颜色不因选择改变

- `OxygenSelectionChrome` 不再把顶栏/状态栏混到 Grey 600 `#757575` / Grey 700 `#616161`，也不再走强调色压暗派生。
- `targets` / `frame` 始终读当前主题表面与前景；`move` 强制 `progress = 0` 并立刻重绘，用来覆盖 AppCompat CAB 的 primary 着色，但不再做颜色过渡动画。
- 进入选择、拖选中、数量更新、退出选择：顶栏表面、状态栏配套色、图标/标题前景都不切换目标色。
- 选择数量文案、关闭/返回、操作菜单仍由 Commons CAB 承载；业务归属不变。勾选仍可用强调色。

### 2. 选中/取消动效（对照附件）

对照附件 1（当前实现录屏）与任务说明中的谷歌相册选择观感。附件 2 文件名指向「文件夹进入和缩略图放大缩小」；逐帧核对后**该附件不含选择态**（无长按、勾选、拖选、CAB），因此动效参数以附件 1 暴露的硬切问题 + 既有谷歌相册选择约定为准，而不是凭附件 2 的 Viewer 共享元素去猜选择节奏。

| 参数 | 值 |
| --- | --- |
| 缩略图缩放 | `CONTENT_SCALE = 0.88` |
| 时长 | `SELECTION_CONTENT_MS = 180`；拖选单格 `SELECTION_SWIPE_MS = 100` |
| 缓动 | `PathInterpolator(0, 0, 0.2, 1)` |
| 勾选起点 | `CHECK_START_SCALE = 0.5`，与缩放同进度 |
| 勾选过渡 | 同一 oval 从空心描边插值到强调色实心，避免 hollow→solid 单帧硬切；选择态内透明度不低于空心底线 |
| 露底 | `#E8E8E8` |
| 列表 | 只缩略图 + 勾选，不缩放整行 |
| 全选 | 仅可见项播放；屏外/回收直接终态 |

拖选矩形结算（`OxygenSelectionDrag`）沿用上一轮：锚点到指尖的包围盒、ACTION_DOWN 固定模式、缩回矩形恢复手势前状态；松手前计数随 toggle 同步。

## 与两份录屏的对照结论

| 场景 | 附件 1（当前实现） | 本包目标 |
| --- | --- | --- |
| 长按进入 | 缩略图有内缩；勾选偏硬切；顶栏先强调色/后灰 | 内缩 + 勾选连续插值；顶栏保持主题色 |
| 点选/取消 | 缩放较顺，勾选易弹入 | 缩放与勾选同向、可中断；快速连点不换图 |
| 拖选/拖取消 | 矩形范围可用；拖选中顶栏变灰 | 范围不变；拖选中顶栏也不变色 |
| 退出选择 | 内容可还原；顶栏硬切回主题 | 内容/勾选按同一时钟还原；顶栏无变色可切 |
| 附件 2 | 无选择态片段 | 不作为本阶段选择验收源 |
