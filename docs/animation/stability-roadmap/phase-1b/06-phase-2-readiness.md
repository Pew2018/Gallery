# 阶段 2 准入

受控测试覆盖这轮数据身份、删除世代、部分扫描挂起、布局安全提交、Viewer 门票和 4,981 项渐进替换后的回位。阶段 1A 诊断继续明确区分枚举完成、worker 终态、来源接受和 Adapter 提交。源日志的 30 次返回目标帧仍报告呈现不可观测。

正式进入 Transition Coordinator 前，需补齐同机稳定/变化目录的 50 次正常 Viewer 往返与撤权；验证同时打开独立消费者时的重复扫描；在 Pixel 8 Pro 上重复 1,500、3,080、约 5,000 和合成 10,000+ 项的冷/热滚动对照，关联版本、可见图片、复绑、测量以及内存；复验 .nomedia 新增、回收站恢复和快速双点。配置相册的仪器回位结果与全套其余失败分别记录。

动画和跨窗口真实像素交接依旧开放。需要修复版的 Pixel 8 Pro 原始日志、录屏及已安装 APK 核验，并保留可配对的帧或合成器证据。当前阶段 2 准入结论为 OPEN。
