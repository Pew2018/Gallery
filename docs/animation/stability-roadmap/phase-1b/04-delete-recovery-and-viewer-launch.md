# 删除、同路径恢复与 Viewer 并发

`ViewerDeletionLedger` 以 Viewer launch 与路径合并 reenter/result 的重复删除交付，并用活动的来源请求代际保留屏障。旧扫描、缓存和部分结果继续被屏蔽。删除后新一代完整来源若包含相同路径，只对这些候选后台验证文件存在，再通过当前请求和访问门接纳。后续权威包可重新显示原来的媒体或同路径替换内容。成功回收站恢复增进已有内容修订号。路径为空的最后一张删除沿既有结果路径同步。

`ViewerLaunchGate` 为普通和自定义配置入口共享。先取得一次异步 handoff 的门票，后台有界验证，主线程消费当前门票后才启动。原有 launched 锁延续到 Activity result。清理尚未完成的返回阻止下一次打开。取消、拒绝、失败、撤权、销毁与过期回调退回各自的请求。异步 handoff 只清理自己持有的邻近窗和 Grid order ID，ViewPager 保留原有独立权限校验。

配置回位使用 Viewer 关闭时媒体路径与当前 Adapter 版本。返回前的通用锚点在定位时取消，新的返回锚点以实际目标媒体为准。最终列表在返回目标尚待解析时仍可推进，目标被共享元素映射后保留现有 Adapter 租约。共享元素回调与窗口像素确认继续使用既有路径。
