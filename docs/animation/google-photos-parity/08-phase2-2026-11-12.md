## 本轮改动

- 为 `MediaAdapter` thumbnail 增加独立 `media_bound_path` 身份标签，并在回收时清除。
- 照片共享进入源、返回等待和 shared-element remap 增加 path identity 校验；已有 request/loaded key 校验保留。提取纯逻辑 `PhotoViewerReturnTarget` 并添加 JVM 用例。
- 自定义照片配置设备测试现在明确断言返回目标在离开 Viewer 前为 offscreen，返回后绑定身份正确，且可见缩略图是 Viewer 最后一张照片。
- 既有手势长序列在 UiAutomation 回报未注入且路径未变化时允许一次重注入；仍逐步断言每次到达指定相邻媒体身份。
- 未调整共享动画 120ms、文件夹淡入 100ms 等参数，也未改主页排序、渐进扫描、缩略图加载策略和收藏授权逻辑。

## 结论边界

- 已确认返回 mapping 会同时验证 adapter path、已加载 request token 和 ImageView 的媒体绑定身份；新增 offscreen 自定义 Viewer 回归通过。
- 相册/收藏共享封面、图片比例与 custom profile 身份路径在本次模拟器部分通过。但下滑长用例重跑失败，且 screenrecord 编码器不可用，因此本轮没有通过完整手势回归或像素级连续画面验收。
- 模拟器测试只证明可用 API 29 仿真设备上的行为路径与截图状态，不能替代 Pixel 8 Pro 真机、帧时间或硬件性能测试。预测性返回、SystemUI 边缘返回、视频慢解码、快速重复进入/退出等依旧未在此轮覆盖。
