# 收藏密码保护实机验收清单

目标设备：安装本次 FOSS Release APK 的 Android 设备。每项保存操作前后截图；测试数据使用可删除的副本。

## 收藏访问与来源保护

- [ ] 新安装、收藏密码关闭：公开来源文件可加入、显示缩略图、打开图片和视频、左右滑动、播放幻灯片。
- [ ] 关闭收藏密码：从仍锁定的来源目录尝试单项和多选收藏；确认出现说明与“启用收藏密码”入口，数据库中没有新增收藏。
- [ ] 启用 PIN 或图案：配置后进入虚拟收藏必须先验证；取消或输错时无收藏媒体、缩略图或详情出现。
- [ ] 启用保护：在来源目录已解锁后，将受保护媒体单项和多选加入收藏；验证后才显示。
- [ ] 已收藏后给来源目录加锁：当前界面立即清空该媒体缩略图和内容；尝试搜索、滑动、幻灯片、查看器、播放器及分享入口，不得继续读到该媒体。
- [ ] 关闭收藏保护时仍留有受保护来源收藏：确认关闭被拒绝，收藏记录和当前有效收藏会话不变。
- [ ] 取消这些收藏后关闭保护；确认公开来源收藏仍能正常访问。
- [ ] 关闭保护后移除来源目录锁，重新打开或刷新虚拟收藏；确认重新读取后公开媒体恢复显示。
- [ ] 从备份导入公开与受保护来源路径：公开项目可导入；受保护路径显示跳过说明且不写入收藏表。

## 生物识别与会话

- [ ] 设置生物识别主方式，随后确认备用 PIN/图案；检查主类型仍为生物识别，备用类型独立。
- [ ] 下次进入虚拟收藏，系统生物识别提示应自动出现；成功后查看图片、视频、滑动及幻灯片不重复验证。
- [ ] 分别测试一次未匹配后继续尝试、系统取消、锁定、设备无可用生物识别、用户取消备用弹窗、备用凭据错误和备用成功。
- [ ] 查看器旋转、短暂切换其他 App、打开视频播放器并返回；会话仍只覆盖当前仍收藏且来源状态未变的路径。
- [ ] 修改/关闭密码、取消收藏、移动媒体、改变来源保护后，旧查看器或播放器不能继续读取内容。
- [ ] 在任务仍保留时杀死应用进程，再由旧任务 Intent 恢复；确认进程内旧 token 不能恢复授权。
